# Skeet Legacy 8802 — Clover API 1.0

[Скачать сборку с Clover API](Skeet_Clover_API_8802.zip?raw=true).

При запуске DLL создаёт `clover_api_8802.lua` в рабочей папке игры, если файла там ещё нет. Из своего Lua-скрипта используйте `local api = require('clover_api_8802')`. Существующий файл с таким именем сохраняется.

[Документация и пример](LUA_API_RU.md) · [Исходный модуль Lua](clover_api_8802.lua)

Версия 1.0 использует штатный Lua API: доступные настройки через ui.reference/get/set, события, отрисовку, сущности и другие доступные функции хоста. Доступ ко всем внутренним полям Skeet и перечисление всех контролов не реализованы.

Архив сохраняет предыдущие изменения меню: отключён Hit chance override, удалён редактор наклеек и отдельные Night mode / Override sky, Draw logs и Watermark находятся в Visuals. Встроенный Lua пока виден в списке.

Проверены Windows x86 сборка, изолированный Lua API, загрузчик и сохранение существующего файла. В игре не проверялось.
