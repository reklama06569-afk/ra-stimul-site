# Skeet Legacy 8802 — UI Bridge Fix

[Скачать новую сборку: DLL, инжектор и полные исходники](Skeet_UI_Bridge_Fix_8802.zip?raw=true).

Это обновление предыдущего Console Bind Fix. Используйте bin/skeet.dll из нового архива.

## Исправления

- Встроенный Lua больше не вызывает функции DLL через FFI. Обмен идёт через скрытые штатные элементы UI и нативные callbacks. Убран прежний источник ошибки cannot call this C function.
- Пропавший heartbeat больше не запускает повторные автоматические загрузки.
- Убраны **только шестерёнки Ragebot**. Его настройки и бинды возвращены в штатные строки GameSense.
- Категории Visuals и Enemy ESP preview сохранены. Текстовое поле Custom skybox теперь поддерживается при переносе настроек в новое меню; его появление больше не вызывает возврат к штатным панелям.
- Ввод в текстовые поля Visuals и Skinchanger передаётся исходным контролам и callbacks. Это включает поиск наклеек.
- Из watermark также убраны вызовы движка через FFI. Адрес Server IP в этой версии недоступен; CPU/RAM/память игры используют новый мост.

## Установка

1. Полностью закройте игру.
2. Распакуйте архив в новую папку.
3. Используйте новую bin/skeet.dll и запустите игру заново.
4. В Skinchanger выберите оружие в Weapon skin. Наклейки редактируются для выбранного оружия, в четырёх слотах.

Цель — CS:GO Legacy 8802 x86. В этой версии после ручной выгрузки встроенного Lua для его восстановления потребуется перезапуск игры.

## Проверки

Пройдены сборка Windows x86, Lua при полностью недоступном FFI, реальный x86 диспетчер callbacks, обмен настройками Night mode и четырьмя слотами наклеек, 60 сценариев жизненного цикла Visuals, 31 сценарий Skin UI, ввод текста и блокировки, 200 подставных материалов Night mode. Хостовая проверка обработчика прошла AddressSanitizer/UndefinedBehaviorSanitizer.

**Игровой запуск и изображение на GPU пока не проверены.** Свежий сводный отчёт: reports/ui_bridge_fix_validation.json; в нём перечислены свежие проверки. Остальные отчёты и документы архива могут описывать предыдущие версии.
