# Skeet Legacy 8802 — очистка меню

[Скачать сборку с очисткой меню](Skeet_Menu_Cleanup_8802.zip?raw=true).

Убраны Hit chance override с биндами и соответствующий патч, редактор наклеек, отдельные Night mode и Override sky. Штатный Brightness adjustment сохранён.

Превью Enemy ESP уменьшено по высоте. Штатная палитра рисуется выше превью, а когда она открыта, превью не перехватывает ввод. Draw logs и Watermark перенесены в Visuals; события Hit, Miss и Purchase выбраны по умолчанию.

**Ограничение:** встроенный Lua автоматически загружается, но остаётся видимым в списке Lua. Скрытие пока не реализовано.

Сборка Windows x86, изолированные проверки Lua, геометрии и моста прошли. Игровой запуск, палитра и отображение на GPU не проверены. Старые отчёты в архиве могут относиться к предыдущим версиям.

Чтобы применить сборку, полностью закройте игру, распакуйте архив и замените DLL на bin/skeet.dll. Затем запустите игру заново.
