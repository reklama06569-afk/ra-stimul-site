# Skeet Legacy 8802 — Clover Lua API 2.0

[Скачать сборку с API 2.0](Skeet_Clover_API_2_8802.zip?raw=true)

[Документация и примеры](LUA_API_RU.md) · [Исходный модуль Lua](clover_api_8802.lua)

В Lua скриптах: `local api = require('clover_api_8802')`. API позволяет обращаться к поддерживаемым хостом настройкам Rage, AA, Visuals, Misc и других разделов, создавать контролы через штатные конструкторы, изменять значения и видимость и подписываться на callbacks. Доступность названий, разделов и типов зависит от встроенного Lua-хоста.

Прямое изменение закрытых внутренних полей, перечисление всех контролов, переименование и перемещение штатных элементов не реализованы. Это расширение существующего API, а не полный доступ ко всем внутренностям.

Чтобы перейти с API 1.0, скопируйте из архива файл `clover_api_8802.lua` в рабочую папку игры с заменой прежнего, замените DLL на новую и перезапустите игру. Установщик DLL автоматически создаёт файл только если его там ещё нет.

Lua-тесты и сборка Windows x86 пройдены. Движок и графика в игре не проверялись. Встроенный Lua по-прежнему виден в списке.
