# Skeet Legacy 8802 — исправление Lua и режимов бинда

[Скачать ZIP с DLL, инжектором и полными исходниками](Skeet_Console_Bind_Fix_8802.zip?raw=true).

В bin/skeet.dll находится пересобранная DLL Windows x86. Исходники — в source/, проверки — в tests/, результаты — в reports/.

## Что исправлено

- Убрана зависимость встроенного Lua-модуля от отсутствующего ffi.load. Загрузчик подставляет адреса фиксированных функций моста для текущего процесса.
- Открытое штатное меню режимов бинда проверяется по его реальному признаку +0x64.
- Окно шестерёнки рисуется на глубине 0.2, штатное меню режима — на 0.15, поэтому оно располагается поверх окна.
- Исправлены время жизни буфера UI::GetName и возврат nullptr при отсутствии имени конфигурации.

## Применение

1. Полностью закройте игру.
2. Распакуйте ZIP целиком в новую папку.
3. Используйте bin/skeet.dll из этого архива вместо старой DLL.
4. Запустите игру заново с этой DLL. Правой кнопкой по полю клавиши откройте меню режима бинда.

Цель сборки — CS:GO Legacy 8802 x86. Исправления не предназначены для CS2.

## Проверки и ограничения

Сборка Windows x86, закрытые проверки Lua без ffi.load, загрузчика и интерфейса пройдены. Исходный обработчик x86 проверен на выбор всех четырёх режимов мышью и запись режима в общую модель бинда.

Игровой запуск и визуальное поведение на GPU в этой среде не проверены. Свежие результаты: console_bind_fix_validation.json, lua_ui_validation.json, addon_bootstrap_validation.json, menu_interaction_validation.json, override_preview_validation.json и visuals_validation.json в reports/. Остальные отчёты архива относятся к предыдущей сборке.
